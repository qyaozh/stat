# 心理与教育统计

这里是张庆垚“心理与教育统计”的资料，仅供学习交流。

## 数据

数据`well`在R程序包`Keng`之中。安装`Keng`后，使用以下R代码调用数据：

```r
data("well", package = "Keng")
```

使用以下命令查看数据介绍：

```r
?well
```
