## 《心理与教育统计》

欢迎访问STAT.PSYCH.PUB！这是张庆垚《心理与教育统计》的配套网站，服务于统计学的教学。《心理与教育统计》数字资源的版权归出版社所有。

## 目录

- 数据
- R代码
- Shiny应用

## 数据

该教材使用的数据`well`在程序包`Keng`之中。使用以下代码调用数据：

```r
library(Keng)
data(well)
```

使用以下命令查看对于数据的介绍：

```r
?well
```
